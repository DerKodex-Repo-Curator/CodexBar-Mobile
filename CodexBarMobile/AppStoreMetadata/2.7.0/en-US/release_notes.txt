• The CodexBar widget can show the providers whose weekly limits reset soonest. In its Overview, set Provider Selection to By Weekly Reset (Soonest First) and choose 2, 3, or 4 providers, in any widget size.
• The widget uses this order whichever order your Usage cards use, and shows each provider's weekly usage and reset time. Choose Manually works as before.
• On iOS 27 or later, CodexBar widgets added with CodexBar 2.6 or later show the new option right away. Other CodexBar widgets need to be added again from the widget gallery to show it.
• Grok's weekly limit is now recognized, so Weekly Reset (Soonest First) sorts Grok by its next reset instead of showing No weekly reset.
