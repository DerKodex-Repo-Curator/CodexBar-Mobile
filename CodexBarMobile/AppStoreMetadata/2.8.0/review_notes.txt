CodexBar is an iPhone/iPad companion for the Mac app. No separate account login is required. For review without a Mac, dismiss the initial Release Notes with Done, then tap View Demo on the Usage tab while it shows Waiting for Mac Sync to explore synthetic provider usage and costs. Live data requires the Mac companion on the same iCloud account. Mac download: https://github.com/o1xhack/CodexBar-Mobile/releases . Version 2.8 displays nine more providers synced from the Mac (Aerostack, Cosmic AI, Tavily, Exa, Linkup, TinyApi, Sail Research, Sofya, X API), the X API credit balance, Qwen Cloud team plan labels, Claude plan renewal dates, an estimate marker for estimated usage, and more translated provider details. All data comes from the user's own Mac through their private iCloud database; the iPhone makes no provider network requests. The paired Mac version is 0.74.1.1 Mobile 2.8.0.
